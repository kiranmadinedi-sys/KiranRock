03 / Trade Flow
How a Trade Happens
Every 5 minutes during market hours, this 13-step pipeline runs autonomously for each AI-enabled user.
1
⏱️ Scheduler Tick
Enhanced AI Scheduler fires every 5 minutes — only during 9:30 AM–4:00 PM ET, Mon–Fri, no holidays.
2
🛑 Kill Switch Check
Checks Redis pantheon:HALT_ALL and DB global_trading_control. Either set → skip cycle entirely.
Risk Gate
3
👤 Load AI-Enabled Users
SELECT users WHERE ai_trading_enabled = true. Each user gets their own risk_config from DB.
4
🔍 Market Screener
Scans ~20 symbols. Filters: price > $10, volume surge, RSI not overbought. Returns top candidates.
AI Screener
5
🩸 Bleeding Symbols Gate
Skip symbols with ≥60% loss rate in last 30 days. Also skips if earnings are within 3 days.
Risk Gate
6
📊 PANTHEON Technical Scoring
12-component AI score: Trend Template (0–25) + Pattern (0–20) + CANSLIM (0–20) + Volume + R:R + News. Pre-score ≥ 55 required to proceed.
Multi-model Ensemble
7
🤖 ORACLE — Claude AI Verdict
Claude runs a bull-vs-bear 8-step debate. Returns TRADE (+10), WATCHLIST (0), or SKIP (−15). Falls back to Ollama if Claude unavailable.
Anthropic claude-sonnet-4-6
8
🎯 Final Threshold Check
Final score ≥ 70 (minBuyScore) → proceed. Below 70 → skip. This threshold is configurable per-user in risk_configs.
9
⚖️ Kelly Position Sizing
SCALE agent calculates position size using Kelly Criterion. Max 15% cap. Checks max open positions, sector limits, available cash.
10
🏦 Broker Execution
Places order via Alpaca Paper API. Falls back to simulated PostgreSQL trade if broker unavailable. Order logged: CREATED → VALIDATED → SUBMITTED.
Alpaca API
11
⚡ Redis State Update
Updates pantheon:POSITIONS_OPEN:{userId}. Pings ARROW agent health. Prevents double-buys across EC2 instances.
12
📱 Telegram Alert
Sends formatted trade alert to user's registered Telegram chat_id with symbol, score, price, stop-loss target, and AI reasoning summary.
Push Notification
13
📉 Stop Loss Monitoring
Every cycle checks all open holdings: Hard stop −3%, Trailing stop −3% from peak, Take profit +15%. Auto-sells and logs CLOSED → JOURNALED.
Risk Control

07 / Security & Risk
Risk Controls & Security
Four-layer kill switch system, JWT auth, bcrypt passwords, parameterized SQL, and 6 automated circuit breakers protect the platform and capital.

🛑 Kill Switch Layers

1Redis HALT_ALLinstant, cross-process
2global_trading_controlDB — all users
3user_trading_controlsper-user switch
4risk_config limitsautomated circuit breakers

⚡ Circuit Breakers

📉
5 consecutive losses
CIRCUIT_HALT_STREAK → halt all trading
📊
Portfolio drops 15% from peak
MAX_DRAWDOWN_PCT → halt all trading
📏
VIX ≥ 35
MAX_VIX → halt trading — too volatile
⏰
Market data older than 2 min
DATA_MAX_AGE_MS → halt, set DATA_STALE

🔐 Authentication & Security

🔑
JWT Bearer Tokens
64-byte random secret. Verified on every API route via protect middleware.
🔒
bcrypt Password Hashing
Rounds = 10. Passwords never stored or logged in plaintext.
🛡️
Helmet Security Headers
XSS protection, CORP, HSTS, frame guards on all responses.
💉
Parameterized SQL
All queries use $1, $2 placeholders — zero SQL injection risk.
🚦
Rate Limiting
100 requests / 15 min per IP. TG exponential backoff (3 retries).
📝
Append-Only Audit Log
order_audit_log: no UPDATE or DELETE ever issued — full immutable history.
