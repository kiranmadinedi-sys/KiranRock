# CLAUDE.md - Stock Analysis Instructions

## Purpose
Automate pre-market stock analysis using Claude Code CLI. This file provides prompts and instructions for Claude to analyze selected stocks before the market opens.

## Instructions for Claude

1. Analyze the following stocks for pre-market trends, news, and technical signals:
   - AAPL
   - MSFT
   - TSLA
   - AMZN
   - GOOGL

2. For each stock, provide:
   - Pre-market price movement summary
   - Key news headlines impacting the stock
   - Technical analysis (support/resistance, momentum)
   - Any unusual options or volume activity

3. Summarize overall market sentiment and highlight any actionable insights.

---

## Example Prompt
Analyze the pre-market trends, news, and technical signals for AAPL, MSFT, TSLA, AMZN, and GOOGL. Provide a summary for each stock and an overall market outlook.

---

## Usage
- Run: `claude /run CLAUDE.md`
- Or integrate with backend scripts to automate this analysis before market open.
